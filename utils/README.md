# Decoding Bulk Raw Files

## Steps

1. **Install dependencies**

   Make sure you have Python installed, then install the required packages:

   ```bash
   pip install -r requirements.txt
   ```
2. **Download the raw data file**

    Retrieve the file you want to decode from Beehive.

3. **Run the decoder**

    Execute the script with your data file as an argument:
    ```
    python3 datafile-decoder.py NAME-OF-DATAFILE.txt
    ```
    This will generate a decoded CSV file in the same directory.
